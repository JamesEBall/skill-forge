# Tables, figures, boxes, headings, and other layout

From the Tables, Figures, Boxes, Headings, Appendixes, Executive Summaries, Glossary, Page Numbers, and Photo Captions entries of the ADB *Handbook of Style and Usage* (2024 edition). These formats are required in Board documents; publications may follow them.

## Tables

Use a table only when it adds to the text. Mention every table in the text and place it right after the paragraph that first mentions it. Try to keep it on one page; if it must run over, use facing pages and repeat the column heads.

**Label and title**

- One table in the document: title only. Two or more: Table 1, Table 2, in order of appearance.
- "Table 7: Sovereign Operations, 2022–2023", centered above the table, bold, title case, 11 point.
- Short and descriptive. Do not repeat the column heads. Years or dates last, after a comma. Leave out the country name in a single-country document.
- Spell out abbreviations in the title (except ADB and ADF) and do not add them in parentheses.
- Unit of measurement centered on the next line, same size, not bold, in parentheses, lowercase, singular, no "in": ($ million), ($ billion), ($'000), (%). Not (in $ million), ($ Million), ($Bn), (1,000s).
- In appendixes: Table A1.1, Table A1.2 in the first appendix; Table A2.1 in the second; Table A.1 if there is only one appendix. A single table in an appendix is Table A1, Table A2 (title only if it is the only appendix). An appendix that is nothing but one table takes the table's title in bold capitals as the appendix title.

**Columns and body**

- Every column has a head in title case; use "Item" if nothing better fits. Left-align the first head, center the others, bottom-align heads that run over more than one line.
- First column text in sentence case; subheadings within it in title case.
- Same unit throughout: align on the decimal point, centered under the head, same number of decimal places. Mixed units: right-align.
- Mostly numbers: three horizontal rules only. Mostly words: a single-line frame with vertical rules is allowed.
- Bold for the title, column heads, subheadings, subtotals, and totals. Font 9 to 11 point, consistent across the document.
- Top-align entries in a row when some run over several lines.
- Text tables: a period only after a complete sentence. Use sentences or fragments consistently, at least within each column.
- No ampersands. Slashes allowed in column heads to save space.
- Do not wrap text around a small table; center it.

**Symbols**

| In a cell | Means |
| --- | --- |
| (blank) | the column does not apply |
| ... | data not available |
| 0 | magnitude zero |
| (5.3) | negative; define below as "( ) = negative." Never a hyphen, en dash, or minus sign |

Define every symbol below the table.

**Below the table**, 9 point, in this order, each on its own line:

1. Abbreviations in alphabetical order: `ADB = Asian Development Bank, GDP = gross domestic product, NPL = nonperforming loan.` Define them even if the text already has. (Alternatively spell out at first use inside the table; use one system per table.)
2. `Note:` or `Notes:` for the table as a whole. Run short ones together; number them if there are several or they are long.
3. Footnotes with superscript lowercase letters (a, b, c), assigned left to right, top to bottom, set flush against the word or number. The same letter may be reused for the same note. Double footnotes are allowed in tables.
4. `Source:` or `Sources:`. Every table in a Board document has one. See `citations.md`.

Standard notes: `Note: Numbers may not sum precisely because of rounding.` and `Note: Percentages may not total 100% because of rounding.`

Example:

```
                Table 1: Financing Plan

Source          Amount        Share
                ($ million)   (%)
ADB              90.0          60.0
JFPR             45.0          30.0
Government       15.0          10.0
  Total         150.0         100.0

ADB = Asian Development Bank, JFPR = Japan Fund for Prosperous and Resilient Asia and the Pacific.
Source: ADB estimates.
```

## Figures

- Same principles as tables: mentioned in the text, placed after that paragraph, never longer than a page.
- Framed, with the title, abbreviations, notes, footnotes, and sources inside the frame. Full-page organization charts and problem trees need no frame.
- "Figure 7: Time Spent on Domestic and Care Work in Fiji in 2016, by Sex and Age", centered above, bold, title case; unit below in parentheses: (% of time), ($ million).
- Numbering as for tables: Figure A1.1, Figure A.1, Figure A1. Cite as "(Appendix 3, Figure A3.2)", not "(Figure A3.2 in Appendix 3)".
- Two-dimensional charts only, except in brochures, fact sheets, and similar awareness materials.
- No ampersands: industry and trade.
- Explanatory material in the same order as tables, 9 point. A source for every figure.

## Boxes

- Use sparingly, and refer to each in the text. Ideally one page, never more than two (on facing pages).
- "Box 3: Phnom Penh Water Supply and Drainage Project", bold, title case, centered. One box only: title with no label. In books: Box 3.1, Box 3.2.
- Font 1 point smaller than the text, justified, short unnumbered unindented paragraphs with a half line between them.
- Self-contained: abbreviations spelled out again; footnotes lettered (a, b) and placed at the end of the box before the source. A term first abbreviated in a box is spelled out again when it next appears in the text.
- Avoid tables and figures inside boxes. If unavoidable, do not number them.

## Headings (Board documents)

At most four levels:

```
V.  FINANCIAL AND ECONOMIC EVALUATION        level 1: Roman numeral, capitals
A.  Economic Benefits                        level 2: capital letter, title case
    1.  Flood Control                        level 3: Arabic numeral, title case
        a.  Flood Damage to Crops            level 4: lowercase letter, title case
```

- Never a single heading at any level. If there is only an "a." with no "b.", remove it.
- No abbreviations in headings except ADB and ADF, even if already defined, and none added in parentheses. No footnote indicators.
- Title case. Hyphenated words: capitalize each element except articles and coordinating conjunctions (Salary-Related Benefits, Over-the-Counter Markets, Net-Zero Economies, Anti-Money-Laundering Activities). Prepositions of five or more letters are capitalized (Through, Toward, Across).
- **Run-in heads** serve as a fifth level or to set paragraphs apart: bold, sentence case, a few words, followed by a period, not a full sentence. They may use an abbreviation already introduced in the text but should not introduce one ("**Weak public financial management.** Economic shocks have ... exposed public financial management (PFM) challenges.").
- Do not put topic sentences in bold in Board documents.

## Appendixes and annexes

- An appendix depends on the main paper. An annex can stand alone.
- Refer to every appendix in the main text and number them in order of mention (templates may fix the order). A single appendix is "the Appendix".
- Capitalize a specific reference: "(Appendix 2)", "in the Appendix".
- Each appendix restarts: abbreviations are spelled out again, footnotes begin at 1, paragraphs (in a text appendix) are numbered from 1.
- Title in capitals, centered. Running head "Appendix 1" with the page number.
- No attachments or annexes to appendixes. No verbatim repetition of the main text.
- List all appendixes in the contents.

## Executive summaries

- Written last. Key points, findings, and recommendations in fresh, concise wording, using the same terms and the same numbers as the report.
- No excessive background, no pasted passages, no footnotes, tables, or figures.
- 1–2 pages for most Board documents; never more than 10% of the main text.
- Board documents: paragraphs unnumbered, not indented, separated by one line. Pages in lowercase Roman numerals, none on the first page.

## Glossary

Include one when the document has three or more technical terms, many non-English terms, or words not in Merriam-Webster. Format: `aimag – province`. With only one or two such terms, define each at first use in the text or a footnote. Use glossary terms consistently, and do not mix English and local names for administrative units (if aimag, then soum) unless the country itself does.

## Page numbers (Board documents)

- Lowercase Roman numerals for front matter; Arabic for the rest.
- Upper outside corner: left on even pages, right on odd pages.
- None on the contents page, the first page of the summary, or the first page of the main text. Keep it on the first page of each appendix.

## Photo captions and credits

- Caption below the photo: a bold descriptive title ending in a period, then a sentence on the photo's relevance.
- One source for all photos: a general credit in the preface, acknowledgments, or copyright page. Several sources: credit each in parentheses at the end of the caption, "(photo by Samir Jung Thapa)".

## Front-matter notes that the text depends on

- Currency equivalents with the exchange rate and date.
- `In this report, "$" refers to United States dollars.`
- Fiscal year definition: `The fiscal year (FY) of the Government of Palau ends on 30 September. "FY" before a calendar year denotes the year in which the fiscal year ends, e.g., FY2024 ends on 30 September 2024.`
- Abbreviations; Weights and Measures; Glossary.
